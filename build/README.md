# Сборка дистрибутива

Собирается на Windows: PyInstaller не делает кросс-компиляцию.

## Что нужно на машине сборки

- Windows 10 или новее, 64 бита;
- Python 3.12;
- Inno Setup 6;
- около 4 ГБ свободного места.

## Порядок

```powershell
py -3.12 -m venv .venv
.venv\Scripts\pip install -r build\requirements-build.txt
.venv\Scripts\pyinstaller build\app.spec

& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build\installer.iss
```

Результат: `build\output\EngineerAssistant_Setup.exe` — один файл,
который передаётся пользователю.

## Что попадает в дистрибутив

Всё, включая векторную базу и реестр. Установщик раскладывает файлы сам,
докладывать вручную ничего не нужно.

| Часть | Размер |
|---|---|
| Векторная база и реестр | 453 МБ |
| Модель эмбеддингов | 129 МБ |
| Python и библиотеки | ~250 МБ |
| Итого до сжатия | ~830 МБ |
| Установщик | ~700 МБ |

## Размещение данных

| Что | Куда |
|---|---|
| Программа, база реестра, модель | папка установки |
| Загруженные документы, история | `%LOCALAPPDATA%\Инженерный помощник` |

База реестра только читается, поэтому лежит рядом с программой и не
требует прав на запись. Всё, что добавляет пользователь, пишется в его
профиль — программа работает и при установке в `Program Files`.

## Ключ доступа

`secret.bin` шифруется и в репозиторий не попадает. Записать ключ:

```powershell
.venv\Scripts\python -m app.secrets_store sk-ваш-ключ
```

Если файла нет, ключ читается из `ROUTERAI_API_KEY` или из `.env` рядом
с программой.

Для дистрибутива стоит использовать отдельный ключ с ограничением
расходов: программа расшифровывает его на машине пользователя, поэтому
защита рассчитана на случайное обнаружение, а не на целенаправленное
извлечение.

## Обновление базы

Пересобрать базу командой `build_index.py` на машине разработки, заменить
папку `data` и собрать дистрибутив заново.

## Проверка после сборки

1. Установщик отрабатывает, программа запускается из меню «Пуск».
2. Появляется иконка в трее, открывается браузер.
3. «Сколько всего светильников» — приходит точный подсчёт.
4. «Как обслуживать РИП-12» — ответ со ссылками на документы.
5. Загрузка PDF завершается, документ виден в списке «Мои документы».
6. Выход через меню в трее закрывает процесс полностью.

Первый запуск дольше обычного: загружается модель и открывается база.
