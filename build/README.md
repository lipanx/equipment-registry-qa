# Сборка дистрибутива

Собирается **на Windows**: PyInstaller не умеет кросс-компиляцию, exe
с Linux или macOS не получить.

## Что нужно на машине сборки

- Windows 10 или новее, 64 бита;
- Python 3.12;
- около 3 ГБ свободного места.

## Порядок

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\pip install pyinstaller

# модель эмбеддингов рядом с приложением — иначе оно полезет в интернет
.venv\Scripts\python build\prepare_bundle.py

.venv\Scripts\pyinstaller build\app.spec
```

Готовый дистрибутив: `dist\Инженерный помощник\`.

## Что доложить руками

PyInstaller собирает только приложение. Рядом с exe нужно положить:

```
dist\Инженерный помощник\
├── Инженерный помощник.exe
├── _internal\               ← библиотеки и модель
├── .env                     ← ключ RouterAI
└── data\
    ├── chroma\              ← векторная база (build_index.py)
    └── Реестр_оборудования.xlsx
```

База и реестр лежат **рядом с exe, а не внутри**: при обновлении
приложения проиндексированные документы и загрузки пользователя
сохранятся.

## Размеры

| Часть | Размер |
|---|---|
| Модель эмбеддингов (int8) | 129 МБ |
| Векторная база | 453 МБ |
| Python и библиотеки | ~250 МБ |
| **Итого** | **~830 МБ** |

В установщике после сжатия — примерно 450–550 МБ.

## Почему onedir, а не onefile

`--onefile` распаковывает всё содержимое во временную папку при каждом
запуске. При таком объёме на слабой машине это десятки секунд ожидания
перед стартом.

## Проверка после сборки

1. Приложение стартует, иконка появляется в трее, браузер открывается.
2. Вопрос «сколько всего светильников» — приходит точный подсчёт.
3. Вопрос «как обслуживать РИП-12» — ответ со ссылками на документы.
4. Загрузка PDF через интерфейс завершается, документ виден в списке.
5. Выход через меню в трее закрывает процесс полностью.

## Установщик

Дистрибутив упаковывается Inno Setup. Важное: приложение пишет в свою
папку (`data\`), поэтому либо ставить не в `Program Files`, либо
настроить права на подпапку `data`.
